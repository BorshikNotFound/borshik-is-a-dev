Luau:B Luau:B (Luau: Borshikified) is a programming language meant to bring roblox studio to YOUR computer. Made real (by BorshikNotFound) with Python and Qt. You can find Luau:B on Github. IDE included. NOTE: LUAU:B IS STILL IN DEVELOPMENT.
Overview Luau:B borrows a lot of things from Luau and Roblox Studio (obviously). Expect a lot of similarities. Feel free to use Roblox Studio documentary for some features.
